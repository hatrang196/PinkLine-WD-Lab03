# PinkLine — Timeline & Deadline Tracker

A responsive static web interface built with **HTML5 and CSS** (for **WDLab03**, Part 2) to organize coursework, group projects, part-time work shifts, and personal tasks on a unified timeline.

**Live Demo:** https://hatrang196.github.io/PinkLine-WD-Lab03/

## Key Features
- **Color-Coded Task Groups:** Consistent category badges and progress tracking across four groups (*Học tập*, *Đồ án*, *Ca làm*, and *Cá nhân*).
- **Upcoming & Priority Timeline:** Highlights immediate items and upcoming high-priority milestones sorted by due date alongside overall completion metrics.
- **Weekly Schedule:** Day-by-day view of shifts, study sessions, and deadlines across the week.
- **Task Directory & Detail Views:** Filterable sample task cards (`DL-01` to `DL-12`) with deadlines, priority levels, estimated hours, progress bars, step checklists, and notes.
- **New Task Form:** Built-in HTML5 validation that navigates to a confirmation view upon valid submission (static front-end only; no JavaScript or backend persistence).

## Tech Stack
- **HTML5**
- **CSS3** (responsive layout, including mobile viewport support)
